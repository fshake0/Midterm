## Question 3
What is a web application, and how is it accessed?

A web application is a program accessed through a web browser using the internet.

## Question 4
How does the client-server model work?

The client sends a request to the server. The server processes it and sends back a response.

## Question 5
State one advantage and one limitation of the client-server model.

Advantage: Easy to manage data in one place.

Limitation: If the server fails, users lose access.

## Question 6
What are the roles of the web server, application server, and database?

Web server: Delivers web pages.

Application server: Processes requests.

Database: Stores and retrieves data.

## Question 7
How do Web 1.0 and Web 2.0 differ in user participation?

Web 1.0 mainly allows users to read content. Web 2.0 allows users to create, share, and interact with content.

## Question 8
Name three features of Web 3.0.

Decentralization, blockchain technology, and user control of data.

## Question 9
What is HTML, and how does it structure a webpage?

HTML stands for HyperText Markup Language. It uses tags to organize headings, paragraphs, images, and links.
